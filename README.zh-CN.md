**SubNova** 是一款专注于直观编辑 ASS 字幕的现代 Windows 字幕编辑器。
可以直接在视频上用鼠标编辑位置、旋转、裁剪和绘图，并以与实际播放器完全相同的画面 (libass) 查看结果。

## 主要功能
- **与实际一致的预览** — 使用 mpv 等播放器所用的 libass 渲染字幕，并可按中文名称查找已安装的字体
- **视频上的可视化编辑** — 位置、移动、旋转、缩放、裁剪、绘图（含填充颜色），以及用参考网格贴合视频中平面的**平面透视工具**
- **快速标签工具** — 字体、颜色和不透明度、边框/阴影/模糊、旋转/倾斜、淡入淡出、对齐，点几下即可完成
- **自由的面板布局** — 视频、字幕列表、字幕设置、字幕内容、时间轴、标签、平移时间面板可放在任意位置
- **时间轴** — 自动显示音频波形，可调整块高度，拖动即可修改时间，实时平移时间面板
- **字幕与视频自动关联** — 自动加载同名视频（`name.zh.ass` → `name.mkv`）或以前一起使用过的视频
- **多种格式** — 打开、保存、批量转换 ASS/SSA、SRT、WebVTT、SAMI、TTML、SBV、MicroDVD、SCC、EBU STL、JSON/CSV 等；蓝光/DVD 图像字幕可通过文字识别 (OCR) 导入
- **同步工具** — 平移时间、帧率转换、速度变更、两点同步、以其他字幕为基准同步
- 深色/浅色主题、多窗口、自动更新、文件关联，支持한국어、English、日本語、简体中文、繁體中文

## 安装
1. 从 [Releases](https://github.com/hungbok/subnova-releases/releases/latest) 下载 `SubNova-Setup-<版本>.exe` 并运行
2. 程序为所有用户安装，因此会出现一次管理员确认 (UAC)
   - 如果出现 Windows SmartScreen 警告，请选择“更多信息”→“仍要运行”

## 更新
SubNova 会自动检查并下载新版本。点击“重启并更新”，或在退出程序时自动安装。也可以通过“帮助 → 检查更新”手动检查。
