**SubNova** 是一款專注於直覺編輯 ASS 字幕的現代 Windows 字幕編輯器。
可以直接在影片上用滑鼠編輯位置、旋轉、裁切和繪圖，並以和實際播放器完全相同的畫面 (libass) 檢視結果。

## 主要功能
- **與實際一致的預覽** — 使用 mpv 等播放器所用的 libass 繪製字幕，並可依中文名稱尋找已安裝的字型
- **影片上的視覺化編輯** — 位置、移動、旋轉、縮放、裁切、繪圖（含填色），以及用參考格線貼合影片中平面的**平面透視工具**
- **快速標籤工具** — 字型、顏色和不透明度、外框/陰影/模糊、旋轉/傾斜、淡入淡出、對齊，按幾下即可完成
- **自由的面板配置** — 影片、字幕清單、字幕設定、字幕內容、時間軸、標籤、平移時間面板可放在任意位置
- **時間軸** — 自動顯示音訊波形，可調整區塊高度，拖曳即可修改時間，即時平移時間面板
- **字幕與影片自動關聯** — 自動載入同名影片（`name.zh.ass` → `name.mkv`）或先前一起使用過的影片
- **多種格式** — 開啟、儲存、批次轉換 ASS/SSA、SRT、WebVTT、SAMI、TTML、SBV、MicroDVD、SCC、EBU STL、JSON/CSV 等；藍光/DVD 圖像字幕可透過文字辨識 (OCR) 匯入
- **同步工具** — 平移時間、影格速率轉換、速度變更、兩點同步、以其他字幕為基準同步
- 深色/淺色佈景主題、多視窗、自動更新、檔案關聯，支援한국어、English、日本語、简体中文、繁體中文

## 安裝
1. 從 [Releases](https://github.com/hungbok/subnova-releases/releases/latest) 下載 `SubNova-Setup-<版本>.exe` 並執行
2. 程式會為所有使用者安裝，因此會出現一次系統管理員確認 (UAC)
   - 如果出現 Windows SmartScreen 警告，請選擇「其他資訊」→「仍要執行」

## 更新
SubNova 會自動檢查並下載新版本。按「重新啟動並更新」，或在結束程式時自動安裝。也可以從「說明 → 檢查更新」手動檢查。
