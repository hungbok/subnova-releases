# SubNova

ASS 자막을 직관적으로 편집하는 데 초점을 맞춘 차세대 자막 편집기입니다. SRT, WebVTT, SAMI(SMI)도 지원합니다.

이 저장소는 SubNova의 **설치 파일 배포용**입니다.

## 설치

1. [Releases](https://github.com/hungbok/subnova-releases/releases/latest)에서 `SubNova-Setup-<버전>.exe`를 내려받습니다
2. 실행해서 설치합니다 (현재 사용자용, 관리자 권한 불필요)
   - Windows SmartScreen 경고가 나오면 "추가 정보" → "실행"을 누르세요

## 업데이트

설치한 뒤에는 SubNova가 새 버전을 자동으로 확인하고 내려받습니다. "다시 시작하여 업데이트"를 누르거나, 프로그램을 종료하면 설치됩니다.
도움말 → 업데이트 확인으로 직접 확인할 수도 있습니다.
