**SubNova** は、ASS 字幕を直感的に編集することに重点を置いた Windows 用のモダンな字幕エディターです。
動画の上でマウスを使って位置・回転・クリップ・描画を編集し、実際のプレーヤーと同じ表示 (libass) で結果を確認できます。

## 主な機能
- **実際と同じプレビュー** — mpv などのプレーヤーが使う libass で字幕を描画します。インストール済みのフォントを日本語名でも検索します
- **動画上でのビジュアル編集** — 位置、移動、回転、サイズ、クリップ、描画 (塗りの色を含む)、ガイド格子で動画内の平面に合わせる **平面パース ツール**
- **クイック タグ ツール** — フォント、色・不透明度、縁取り・影・ぼかし、回転・傾き、フェード、配置を数クリックで
- **自由なパネル配置** — 動画・字幕一覧・字幕の設定・字幕の内容・タイムライン・タグ・時間をずらすパネルを好きな位置に
- **タイムライン** — 音声波形を自動表示、ブロックの高さを調整、ドラッグでタイミングを編集、リアルタイムの時間ずらしパネル
- **字幕と動画の自動関連付け** — 同じ名前の動画 (`name.ja.ass` → `name.mkv`) や以前一緒に使った動画を自動で読み込みます
- **多数の形式** — ASS/SSA、SRT、WebVTT、SAMI、TTML、SBV、MicroDVD、SCC、EBU STL、JSON/CSV などを開く・保存・一括変換。Blu-ray/DVD の画像字幕は文字認識 (OCR) で読み込み
- **同期ツール** — 時間をずらす、フレームレート変換、速度変更、2点同期、別の字幕を基準に同期
- ダーク/ライト テーマ、複数ウィンドウ、自動アップデート、ファイルの関連付け、한국어・English・日本語・简体中文・繁體中文

## インストール
1. [Releases](https://github.com/hungbok/subnova-releases/releases/latest) から `SubNova-Setup-<バージョン>.exe` をダウンロードして実行します
2. すべてのユーザー向けにインストールされるため、管理者の確認 (UAC) が一度表示されます
   - Windows SmartScreen の警告が表示されたら「詳細情報」→「実行」を選んでください

## アップデート
SubNova は新しいバージョンを自動で確認してダウンロードします。「再起動してアップデート」を押すか、プログラムを終了するとインストールされます。ヘルプ → アップデートを確認 から手動で確認することもできます。
